Matching criteria

Strict rescue qualification compares normalized breed, recorded sex, and raw age-in-weeks against the selected program profile.

Dashboard workflow

Search, filter, sort, paginate, inspect candidates, shortlist records, review charts/geography, and export CSV output.

Data and attribution

The static browser demo uses a bundled Austin Animal Center dataset snapshot. Third-party data and runtime notices are retained separately from project-owned source.

Project architecture

HTML pages live in pages/ ; page controllers in js/pages/ ; shared components in js/components/ ; shared data in js/data/ ; business rules in js/lib/ ; runtime bootstrap in js/runtime/ ; CSS is split into base, shared component, page-specific, and recovered runtime layers.
